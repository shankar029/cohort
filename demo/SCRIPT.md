# Cohort — Hackathon Demo Script (v6, ~1:52, 13 scenes, under 2:00)

Voiceover: Azure Neural TTS (`en-US-AndrewMultilingualNeural`). On-screen: real footage cut
from a recorded Cohort run, in a branded browser frame with animated captions.

Opens with a ~5s **spoken brand intro** (what Cohort is), then **team creation**, the request
to the team lead, the build, a **verification-gate** arc (reviewer/QA/security catch issues →
new work items), merge, dashboard, and finale. Tightened to fit a strict 2-minute cap.

Legend — **VO** = narration (`vo-scenes.json`); **Caption** = on-screen text.

---

### 0 — Intro (~5s)  ·  Brand animation (logo + Plan → Build → Review → Ship)
- **VO:** "This is Cohort. An A.I. engineering team that runs on your own machine."

### 1 — Create the team  ·  Agents: catalog → roster → model → system prompt (sped)
- **VO:** "It starts with your team. A full roster of specialists: architect, frontend, backend, Q.A., code reviewer, security, and more. Each with its own role and system prompt."
- **Caption:** First, assemble a team of AI specialists

### 2 — Hook  ·  chat, request typed (sped up)
- **VO:** "You send one message to the team lead. No tickets, no board. Just describe what you want built."
- **Caption:** Then send one message — just describe what you want

### 3 — The brief  ·  hit Send + Team Lead reads + plans
- **VO:** "Here, a full personal finance app. Attach a brief, hit send, and that one sentence becomes the plan."
- **Caption:** Attach a brief, hit send — that one sentence is the plan

### 4 — Team online  ·  Team Lead plans parallel streams
- **VO:** "In seconds, the lead consults a product manager, turns it into an epic, and plans the work as parallel streams."
- **Caption:** It becomes an epic — planned as parallel streams

### 5 — Decomposed  ·  Kanban board
- **VO:** "It's decomposed into stream-tagged tasks on a live board. Every specialist works in parallel, each in its own git worktree."
- **Caption:** Decomposed into parallel, stream-tagged tasks

### 6 — Team discussion  ·  multi-agent thread
- **VO:** "And they don't work in a vacuum. Grounded agents brainstorm and align before writing a line of code."
- **Caption:** Grounded agents brainstorm and align first

### 7 — Review catch  ·  Code Reviewer blocks the PR (float bug)
- **VO:** "Then it gets serious. The code reviewer catches a real floating-point bug and blocks the pull request."
- **Caption:** The reviewer catches a real bug — PR blocked

### 8 — Quality gates  ·  Notifications: QA/security/coverage blocked (slowed)
- **VO:** "And it's not just review. Every task must pass Q.A., security, and coverage."
- **Caption:** Every task must pass QA, security & coverage

### 9 — Verification gate  ·  Board fix work item + Task-details + Gate badges
- **VO:** "When a check fails, the lead files it as a new work item and re-runs the gate. Nothing merges until it's green."
- **Caption:** Failures become new work items — then re-verified

### 10 — Merge  ·  Git: PR open + commit history
- **VO:** "Once the bar is met, an independent reviewer signs off, and it's a real merge."
- **Caption:** Quality bar met — reviewed, then a real merge

### 11 — Dashboard  ·  metrics + active-now
- **VO:** "One dashboard keeps you in command. Epics, tokens, and who's active, at a glance."
- **Caption:** One dashboard — the whole operation at a glance

### 12 — Done  ·  final dashboard
- **VO:** "From one sentence, to shipped, reviewed code. Powered by the GitHub Copilot S.D.K. This is Cohort. Your A.I. engineering team."
- **Caption:** From one sentence to shipped, reviewed code
