# Cohort Documentation

Curated docs for Cohort — a local web app that orchestrates GitHub Copilot SDK
agents (a Team Lead + specialists) to get real work done in your repositories.

Start with the [README](../README.md) for install & run, then:

| Doc | Read it for |
| --- | --- |
| [USER-GUIDE](./USER-GUIDE.md) | Day-to-day use: create a project, build a team, give work, review & merge. |
| [ARCHITECTURE](./ARCHITECTURE.md) | How it's built: runtime shape, components, data model, request → merge lifecycle. |
| [CONFIGURATION](./CONFIGURATION.md) | Every `ATEAM_*` env var and per-project setting, with defaults. |
| [AGENTS](./AGENTS.md) | The Team Lead + 12 specialist templates, tool profiles, and custom agents. |
| [DEVELOPMENT](./DEVELOPMENT.md) | Contributing: setup, scripts, testing model, and conventions. |

> Root-level `PLAN*.md`, `EVAL*.md`, and `RUN-*.md` files are internal working
> notes (planning ledgers, eval findings, run monitors), not end-user docs.
