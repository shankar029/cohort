2. Increment detail

  • I1 — Contracts + helpers. Pure, no I/O. Establishes the shared type both server and web compile against, and the URL validation (AC2.1). Session-sized: 2 files, all unit-tested. Must not break the existing local-create schema — the back-compat test is the guard for AC1.
  • I2 — Clone + service + route. The core behavior (AC2) and its failure contract (AC2.2). Depends on I1's types/helpers. Integration tests use a local git fixture repo (created in a temp dir, cloned via file:// path) so no network is needed and the test is fast and deterministic. Failure paths assert a 400 with a user-visible error, no store write, and no hang.
  • I3 — Web UI + E2E. Widens the web input type to the union, adds the import tab to CreateProjectModal (reusing FolderPicker for the parent dir), and proves the surface with Playwright. Depends on I2 (the endpoint must exist).

3. Testing plan

  • Unit (Vitest): isGitUrl (accept https/.git/git@/ssh, reject empty/plain-text/space), deriveRepoName (strip .git, trailing slash, path segments, sanitize), schema back-compat + import validation, importProjectFromUrl name-normalization & no-store-write-on-failure (clone helper mocked).
  • Integration (Vitest, real git): cloneRepoToDir against a local fixture repo; route-level POST /api/projects import happy path + failure paths (malformed URL → 400 before git; unreachable → 400, bounded; target exists → 400).
  • End-to-end (Playwright, Phase 5): modal tabs render; import fields show; malformed-URL inline error; a full import against a local fixture path creates a project and navigates. Reuses the existing webServer harness.
  • Regression scope: existing validateRepoDir.test.ts, fsBrowse.test.ts, git.test.ts, and the create-local e2e (_createdir.spec.ts) must all stay green. Coverage gate (80% lines/fn/stmt, 70% branch over git.ts/store.ts) must hold; new clone.ts and helpers carry their own tests.
  • When full E2E runs: Phase 5, once all three increments are integrated. Final regression pass = full vitest run + playwright test + typecheck + lint.
